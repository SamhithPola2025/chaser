# Chaser
<div style="page-break-after: always;"></div>

Itch.io link to my game (you can play it here online without downloading): https://ezgames2.itch.io/chaser
Youtube link for a demo (no sound in this, but you can experience sound by playing it with the link above): https://youtu.be/0hOKyoZMvnM

A game that I made for the Hack Club Jumpstart program.
Traditionally, you would expect that a character or enemy chases you in a game, but this time, the falling floor is chasing you, and you have to escape and complete all 5 levels!

The game features a player, gravel that slows you down, grass and dirt all with their own sound effects and unique sprites that I made. The goals are flags and you have to reach these to move on. There are also keys and doors, you have to collect keys to open doors to move on within the level if it is required.

Controls:
WASD or arrow keys to move.
R to reset the current level.

Simple controls, complex gameplay.
